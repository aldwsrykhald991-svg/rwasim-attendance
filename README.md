# منصة التحضير — رواسم

منصة عربية (RTL) لتحضير الطلاب داخل البرامج، بهوية جمعية رواسم.

التسلسل: الفريق ← المشروع ← أيام المشروع ← المجموعات ← الطلاب ← حالة الحضور.

## التشغيل

```bash
npm install
npm run dev
```

## متغيرات البيئة

| المتغير | الغرض |
| --- | --- |
| `TURSO_DATABASE_URL` | رابط قاعدة Turso (`libsql://...`). بدونه تُستعمل قاعدة محلية في `prisma/dev.db` |
| `TURSO_AUTH_TOKEN` | مفتاح قاعدة Turso |
| `JWT_SECRET` | مفتاح توقيع جلسات الدخول |

لا تضع هذه القيم في المستودع.

التقنية: Next.js 16 · React 19 · Tailwind CSS 4 · libSQL (Turso).
