# منصة التحضير — رواسم

منصة عربية (RTL) لتحضير الطلاب داخل البرامج، بهوية جمعية رواسم.

التسلسل: الفريق ← المشروع ← أيام المشروع ← محطات التحضير ← المجموعات ← الطلاب ← حالة الحضور.

رابط التحضير المباشر: تحديد الهوية ← مجموعات المشروع ← كشف طلاب المجموعة بضغطة.
يُختار اليوم تلقائياً عند وجود يوم واحد يطابق تاريخ اليوم بتوقيت الرياض؛ وإلا تُعرض أيام المشروع بعد اختيار المجموعة.
يمكن تغيير اليوم من كشف الطلاب. الدخول الأساسي وصلاحيات التحضير محفوظة.

## تحضير الرحلات والتنقلات

داخل اليوم الواحد يمكن إنشاء عدة محطات، مثل «من المركز إلى الحديقة» ثم «من الحديقة إلى المتحف».
من شاشة المجموعة اضغط «محطة جديدة»، اكتب اسم الانتقال، ثم «إنشاء المحطة وبدء التحضير».
كل محطة تبدأ بكشف مستقل غير محضّر. اختر محطة سابقة من القائمة لاستعراضها أو تعديلها وفق صلاحياتك.
المحطة مشتركة بين مجموعات المشروع لذلك اليوم، وتُفتح أحدث محطة تلقائياً في صفحة المجموعات.
زر التحديث يجلب المحطات التي أضافها مشرف آخر. تغيير المحطة محظور أثناء وجود حفظ معلّق.

السجلات السابقة تبقى في جداولها دون نقل أو مسح، وتظهر ضمن «التحضير الأول» في كل يوم.
سجلات المحطات الجديدة وسجل تعديلاتها محفوظة في جداول إضافية. التقارير والتصدير يشملان كل محطة،
ويُحسب عدد الطلاب دون تكرار، بينما إحصاءات الحضور توضّح أنها سجلات عبر المحطات.

## التشغيل

```bash
npm install
npm run dev
```

## الاختبار

```bash
npm ci
npm test
```

يبني الاختبار نسخة الإنتاج ثم يشغّل خادماً محلياً بقاعدة مؤقتة وبيانات تجريبية فقط.
يشمل مسار الرابط المباشر، فرق التاريخ بين الرياض وUTC، اختيار اليوم، الدخول الأساسي، عزل المشاريع والفرق، صلاحيات القراءة والتحضير، وحفظ السجلات السابقة وسجل التعديلات.
يشمل كذلك تعدد المحطات في اليوم، استقلال الحالات والمجموعات، التحضير الجماعي المتزامن، التقارير والتصدير، وترقية قاعدة فيها سجلات سابقة.


## متغيرات البيئة

| المتغير | الغرض |
| --- | --- |
| `TURSO_DATABASE_URL` | رابط قاعدة Turso (`libsql://...`). بدونه تُستعمل قاعدة محلية في `prisma/dev.db` |
| `TURSO_AUTH_TOKEN` | مفتاح قاعدة Turso |
| `JWT_SECRET` | مفتاح توقيع جلسات الدخول |

لا تضع هذه القيم في المستودع.

التقنية: Next.js 16 · React 19 · Tailwind CSS 4 · libSQL (Turso).
